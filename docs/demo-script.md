# 데모 영상 촬영 대본 (약 80초)

**환경**: Pleos Connect Emulator v2.1.0, 앱 "경고등 통역사" 실행, 시뮬레이션 패널 열림  
**녹화**: macOS `Cmd+Shift+5` → 에뮬레이터 창 영역 선택 → "선택 부분 기록" (오디오: 시스템 소리 포함되도록 설정. 안 되면 TTS 음성은 자막으로 대체)

| # | 시간 | 화면 조작 | 들리는 소리 / 자막 |
|---|---|---|---|
| 0 | 0–8초 | 앱 실행 직후. 초록 점 "확인이 필요한 경고가 없습니다" | 🔊 시동 브리핑: "경고등 통역사입니다. 현재 확인이 필요한 경고는 없습니다. 안전 운전하세요." / 자막: **경고등이 켜지면 무슨 고장인지, 계속 달려도 되는지 알려주는 앱** |
| 1 | 8–25초 | 시뮬레이션 패널에서 **타이어 공기압 경고 → 점등** | 🔊 "타이어 공기압 경고입니다. … 서행 주행은 가능하지만 오늘 중 정비가 필요합니다." / 화면 상단 황색 **"서행 주행 가능 · 오늘 중 정비"** 강조 |
| 2 | 25–40초 | **"가까운 블루핸즈 길안내"** 터치 → 내비게이션 화면 전환 | 🔊 "가장 가까운 정비소는 약 2.2킬로미터 거리의 블루핸즈 판교점입니다." / 자막: **NaviHelper로 현재 위치 기준 최단 정비소 길안내** |
| 3 | 40–45초 | 하단 독의 ⚠ 아이콘(경고등 통역사)으로 앱 복귀 | — |
| 4 | 45–60초 | 시뮬레이션 패널에서 **브레이크 경고 → 점등** | 🔊 "더 위급한 경고가 켜졌습니다. 브레이크 경고입니다. … 제조사 매뉴얼은 주행을 멈출 것을 권고합니다." / 카드가 적색 **"즉시 정차"**로 전환, 타이어 경고는 "함께 켜진 경고"로 이동. 자막: **여러 경고가 켜지면 가장 위급한 것부터** |
| 5 | 60–72초 | **"긴급출동 호출"** 터치 → 긴급출동 화면 | 자막: **위치·경고·시각이 정리된 화면을 그대로 읽어주면 접수 끝** |
| 6 | 72–85초 | 브레이크 끄고 **엔진 경고등 → 점멸** | 🔊 "엔진 경고등 점멸입니다…" / 자막: **같은 경고등도 점멸이면 즉시 정차로 승격** |
| 7 | 85–95초 | **경고 블랙박스** 열기 | 자막: **언제 켜지고 꺼졌는지 시간순 기록 — 정비소에 그대로 보여주기** |

## 촬영 전 체크리스트
- [ ] 에뮬레이터는 `ANDROID_EMU_ENABLE_CRASH_REPORTING=0`로 실행 (창 모드)
- [ ] 이전 길안내가 남아 있으면 내비 화면에서 "안내 종료"
- [ ] 시뮬레이션 패널 "모두 끄기"로 초기화 후 앱 재시작 (시동 브리핑부터 시작)
- [ ] Mac 볼륨 확인 — TTS 음성이 녹음되는지 5초 테스트 녹화
- [ ] 영상 끝 자막: "시연의 경고 입력은 시뮬레이션(SIM)이며, 실제 차량 경고등 신호는 Vehicle SDK Telltales로 수신합니다."
